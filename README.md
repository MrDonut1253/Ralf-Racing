Ralf Racing - a 2d top-down racing game that you can play with your friends!
You can host a lobby and share the code with your friends. then you can choose between 4 Maps and race together.
Please keep in mind that its not finished. If you find any bugs, reporting them would help me a lot. Thank you!
If you dont trust the .exe file, feel free to compile the project yourself. For that you need to open the project in Godot, and just export it.

I plan many features for the future, but the main objective is to perfect the networking tech and drive feeling.
